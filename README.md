# language_stat

В файле **Знание_языка_кб.pdf** приводятся результаты локального опроса на знание карачаево-балкарского языка. Этот опрос был проведён, чтобы изучить уровень владения родным языком cреди карачаевцев и балкарцев. Согласно данным [Росстата](https://11.rosstat.gov.ru/vpn2020) по последней всероссийской переписи населения в России проживает 224013 карачаевцев и 124378 балкарцев, из них ~75% (167903 карачаевцев) и ~77,5% (96367 балкарцев) соответственно владеют карачаево-балкарским языком. Таким образом свыше 24% карачаевцев и балкарцев (84121 человек) не владеют родным языком. 

В файле **Результаты опроса про досуг.pdf** приводятся результаты локального опроса про способы проведения досуга среди карачаевцев и балкарцев.

Также прикреплены исходные данные в виде xls-файлов.
